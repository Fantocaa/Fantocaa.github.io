Goravel + Inertia + React

Starting a new web application often means rebuilding the same foundation before working on the product itself: sign-in, protected pages, account settings, navigation, and a dashboard. I made this open-source starter kit so those pieces could work together from the beginning in a Go and React application.

The problem to solve

A login screen on its own is not a usable foundation. The server needs to know which routes require a session, the interface needs the current user and validation errors, and people need a place to manage their account. If these pieces are assembled separately, each new app has to resolve the same connections again.

How I approached it

I used Goravel for the Go backend and Inertia to connect server responses to React and TypeScript pages. The starter includes registration and sign-in, session-based route protection, profile and password settings, and shared authentication and flash-message data. The interface supplies a responsive sidebar, theme switching, and an example analytics dashboard.

The dashboard uses demo figures to show how the interface works.

What this delivers

A developer can start with an application whose basic account and administration flows are already connected, then replace the example screens with the workflows their own product needs. The public GitHub repository contains the source, setup instructions, and license.

Goravel + Inertia + React

Memulai aplikasi web baru sering berarti membangun fondasi yang sama sebelum menyentuh kebutuhan produk: proses masuk, halaman terlindungi, pengaturan akun, navigasi, dan dasbor. Saya membuat starter kit sumber terbuka ini agar bagian-bagian tersebut sudah bekerja bersama dalam aplikasi Go dan React sejak awal.

Masalah utamanya

Halaman login saja belum menjadi fondasi aplikasi yang siap digunakan. Server perlu tahu rute mana yang memerlukan sesi, antarmuka perlu menerima data pengguna dan pesan validasi, dan pengguna perlu tempat untuk mengelola akun. Jika bagian-bagian ini disusun terpisah, setiap proyek baru harus menyambungkannya lagi dari awal.

Cara saya menyelesaikannya

Saya menggunakan Goravel sebagai backend Go dan Inertia untuk menghubungkan respons server ke halaman React dan TypeScript. Starter kit ini mencakup pendaftaran dan proses masuk, perlindungan rute berbasis sesi, pengaturan profil dan kata sandi, serta data autentikasi dan pesan status yang dibagikan ke antarmuka. Ada juga sidebar responsif, pilihan tema, dan contoh dasbor analitik.

Angka pada dasbor merupakan data contoh untuk menunjukkan tampilan, bukan data dari bisnis tertentu.

Hasil yang dibangun

Pengembang dapat memulai dari aplikasi dengan alur akun dan administrasi yang sudah terhubung, lalu mengganti layar contoh dengan kebutuhan produk mereka sendiri. Repositori GitHub publik memuat kode sumber, petunjuk pemasangan, dan lisensinya.
