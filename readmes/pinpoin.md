# Pinpoin: Customer Price Lookup

Pinpoin is a multi-tenant application that helps marketing teams look up the latest price given to a customer. That price provides a reference when deciding what to offer next.

## The problem

When a marketing team needs to prepare a price, it helps to know what the customer was quoted most recently. Pinpoin provides a place to find that information.

## The application

The application uses Laravel and Vue, supports multiple companies through a multi-tenant model, and is self-hosted on a private company server.

[Open Pinpoin](https://pinpoin.tako.co.id/). Access requires a login.
